Arsitektur Background Service Teruji

StoragePlus tidak sekadar mengunggah file biasa. Aplikasi ini menggunakan arsitektur Foreground Service berkategori DATA_SYNC yang dipadukan dengan androidx.work.WorkManager. Saat pengguna memotret gambar atau menerima video di WhatsApp, sistem mendeteksi URI baru dan menambahkan tugas unggah ke antrian sinkronisasi secara asinkron.

Optimasi Daya OEM (Penting untuk Background Sync)

Beberapa merk smartphone (khususnya Vivo, Xiaomi, Oppo, dan Samsung) memiliki pembersih RAM agresif yang dapat mematikan proses background.

Pengaturan untuk Funtouch OS / OriginOS (Vivo V2029 & Seri Lainnya):
  1. Buka Pengaturan > Baterai > Manajemen Konsumsi Daya Latar Belakang.
  2. Cari StoragePlus dan ubah pengaturannya menjadi "Izinkan Konsumsi Daya Latar Belakang Tinggi" (High Background Power Usage).
  3. Buka i Manager > Manajemen Izin > Mulai Otomatis (Autostart) dan aktifkan untuk StoragePlus.
  4. Di menu Recent Apps, tarik ke bawah kartu StoragePlus lalu ketuk ikon Gembok (Lock) agar tidak terhapus saat membersihkan RAM.
Pengaturan untuk MIUI / Xiaomi HyperOS:
  1. Tekan lama ikon aplikasi StoragePlus > pilih Info Aplikasi (App Info).
  2. Aktifkan saklar Mulai Otomatis (Autostart).
  3. Gulir ke bawah ke menu Penghemat Baterai (Battery Saver) > pilih "Tidak Ada Pembatasan" (No Restrictions).
  4. Kunci aplikasi di menu Recent Apps dengan ikon gembok.
Pengaturan untuk ColorOS / Realme UI:
  1. Buka Pengaturan > Baterai > Manajemen Aplikasi Baterai.
  2. Pilih StoragePlus > aktifkan "Izinkan Aktivitas Latar Depan & Belakang" serta "Izinkan Peluncuran Otomatis".
  3. Matikan opsi Optimalkan Otomatis di Malam Hari jika sinkronisasi ingin tetap berjalan saat tidur.
Pengaturan untuk Samsung One UI:
  1. Buka Pengaturan > Perawatan Perangkat > Baterai > Batas Penggunaan Latar Belakang.
  2. Pastikan StoragePlus TIDAK berada di dalam daftar Aplikasi yang masuk mode tidur.
  3. Tambahkan StoragePlus ke daftar "Aplikasi yang tidak pernah tidur" (Never sleeping apps).
  4. Pada Info Aplikasi, pilih Baterai > centang "Tidak Dibatasi" (Unrestricted).

Pertanyaan yang Sering Diajukan

Jawaban lengkap seputar cara kerja, privasi, dan kompatibilitas StoragePlus Basic.

Ya, sangat aman. StoragePlus menggunakan protokol otentikasi resmi Google OAuth 2.0. Kredensial dan token akses disimpan secara aman di perangkat lokal menggunakan enkripsi Android Keystore, tanpa ada pembagian password ke server pihak ketiga. File dicadangkan langsung dari perangkat ke akun Google Drive pribadi Anda.
Izin Foreground Service (tipe DATA_SYNC) diperlukan oleh Android 10+ agar proses pengunggahan foto dan video ukuran besar tidak diputus di tengah jalan saat Anda beralih ke aplikasi lain atau mematikan layar HP. Notifikasi sinkronisasi aktif memberi transparansi penuh saat proses backup berlangsung.
Setiap file foto atau video yang Anda unduh melalui menu Galeri Cloud akan otomatis disimpan di penyimpanan internal perangkat pada folder Download/StoragePlus/ sehingga mudah ditemukan melalui aplikasi File Manager maupun Galeri bawaan HP.
Konfigurasi PIN terhubung ke backend tersinkronisasi. Jika lupa PIN, Anda dapat melakukan reset konfigurasi melalui portal akun terdaftar atau melakukan inisialisasi ulang data aplikasi melalui menu Pengaturan Android > Aplikasi > StoragePlus > Hapus Data.
StoragePlus Basic menyertakan WebView engine khusus yang dioptimalkan dengan ad-pruning dan background playback. Fitur ini memungkinkan Anda mendengarkan streaming musik atau video edukasi tanpa interupsi iklan, dan audio tetap berputar bahkan ketika layar perangkat dimatikan atau saat berada dalam mode Picture-in-Picture.
